## 15. Lessons learned, gotchas and failed approaches (don't repeat these)

### Fetching reference data
- **Wikimedia Commons:** downloads returned 400/404/429, and Commons search is not on the build box's network allowlist. Use the Lucas County iCare parcel photos instead. Use curl for named Commons files; Python urllib gets throttled.
- **County iCare photo API**, step by step:
  1. A search POST with the form fields plus `inpNumber`/`inpStreet`.
  2. `Datalet.aspx?sIndex=0&idx=1`.
  3. `idoc2/photoview.aspx?sIndex=0&idx=1&LMparent=20`. The `var token` is in the page JavaScript. The path `photoview.aspx` without `idoc2/` is a 404.
  4. List photos: `api/documents/Parcel%20Photo/048/<base64 parcel no>?token=`.
  5. Fetch one: `api/document/<id>/standard?token=`.
  - Rate-limit the requests, and retry token fetches with backoff (`parcel_photos.py`: `SHARD=k/n`, `ASSR_ONLY`).
- **UA and identity:** never use the owner's email in a User-Agent. Use `GlassCityBuilder/0.3 (game reference research)`.

### Reading house features from photos
- **Automated feature reading failed:** CLIP zero-shot features (porch type and so on) were no better than chance, so they are hand-labelled from contact sheets of 16 photos.
- **Label code:** `PDSRAP`.

| Letter | Feature | Values |
|---|---|---|
| P | Porch | F full, P stoop, E enclosed, N none, V vacant lot |
| D | Dormer | 0/1 |
| S | Shutters | 0/1 |
| R | Roof | G gable, S side gable, H hip, M mansard, X flat or other |
| A | Awning | 0/1 |
| P | Brick piers | 0/1 |

- **Wall colour:** segformer house mask, exposure-only white-patch gain (≤1.8), then LAB k-means. Score = count·(1+chroma/200).
- **Brick shop blocks:** "light" photo readings are usually shop glass, white trim or sky, so they are ignored (2026-11-21).

### Heights and county records
- **LiDAR heights over houses** are often street trees (15–27 m). Cap residential height by storeys: storeys·3+6. Cap non-residential buildings of up to 4 storeys at storeys·4.3+1.2.
- **AREIS codes:**
  - land use 5xx = residential;
  - 500 with no building = vacant lot;
  - 4xx = commercial (401–404 = apartments);
  - 6xx/7xx = exempt (churches, schools).
  - Structure type (ctype): 2/3/4/5 = houses; 1 = apartments; 11 = mixed; **12 = converted/mixed, a house only on a 5xx parcel**; 20–24 office; 30–35 retail; 40–49 commercial; 60–66 industrial.
  - An 1890s brick block on Main St has ctype 12 on a 4xx parcel.

### Build memory and geometry
- **Out-of-memory in the full build:** `PropList` held a reference to its chunk (a cycle). It now stores ox/oy. Also: a bounded DEM tile cache and a coarser drape grid.
- **Centerline pieces** spanning two chunks caused "chunk rewritten". All pieces now go in the midpoint's chunk.
- **Vertex bloat** (217M verts): trim boxes were about 50% of it. Trim now uses faces-only boxes (`cbox(..., trim=True)`) and one downspout per gutter. Now about 186M verts.

### Terrain
- **Units:** the DEM is uint16 cm above 150 m on a 4 m grid in 500 m tiles (`lidar/dem/<cx>_<cy>.npz`, 125×125, row 0 = north). Game datum = 176 m; water = 174.4 m (game y −1.6).
- **Placement:** buildings sit level at their lowest footprint ground point.
- **Game-side heights:** `Terrain.height(world_pos)` reads `data/terrain.bin`, regenerated by `build.sh`.
- **Spawning:** anything placed by the game (spawns, test teleports, the traffic graph) must use the terrain height, not y = 0. The traffic graph nodes did use y = 0, and the tests teleported the player underground.

### Tests
- **Tests share one world**, so later tests inherit the player's position. Tests that need roads call `_tr_reset_to_spawn()`, which returns to `main.start_pos`, the real spawn.
- **Traffic edge ids** are renumbered on every graph rebuild. Remap `c["next"]` (stale indexes crashed `_step`).

### Replica builder
- **`cornice_profile`** must use exact sizing; it was hugely oversized at first.
- **Arched window heads** must sit on the wall face: the wall over a recessed fan hid it.
- **Check which street a landmark faces before shooting it.** The Eastwood Theater faces E Broadway (west); the first shot showed its back.

### Characters
- **MPFB2 in the bpy module:** importing it as a plain package fails ("package does not name an extension"). It must be installed as an extension (`bl_ext.user_default.mpfb`).
- **Mask modifiers:** evaluated meshes drop masked helper verts (19,158 → 7,992). Read shape-key coordinates directly instead.
- **Opposing slider pairs:** fitting the incr and decr targets as independent columns made both fire together, which produced weird faces. Fit signed sliders first, then refine on the chosen side.
- **Refit after face sliders:** call `HumanService.refit()`, or the eyes, brows and hair stay where they were.

### The build box
- **Hardware:** 2 CPUs, 7 GB RAM, no GPU. Godot and Blender render on the CPU: about 10 min per Godot screenshot and about 1 min per EEVEE frame.
- **Long jobs:** run them with `nohup`, because background tool tasks are killed after 30 min. The full city build takes about 60 min.
- **Concurrency:** never run two Godot instances or a build plus a render at once if RAM is tight.

## 16. Helper scripts (`tools/dbg/helpers/`, run from the work folder)

| Script | What it does |
|---|---|
| `tz.py x,y …` | Terrain height (m above the 176 m datum) at plan coordinates. Use it for screenshot camera heights. |
| `street.py NAME` | Every OSM segment of a street, in plan coordinates (start/end). |
| `facing.py KEY…` | The street-facing direction of buildings (`STREET=` filter). |
| `study.sh KEY ASSR [bands]` | Study sheet: 4 county photos plus the LiDAR height-band raster for one building (`massing_rects.py`). |
| `grp.sh out.jpg key:assr …` | Several study sheets in one image. |
| `getphotos.py` | (`OUT=dir ASSR=a,b,c`) fetches every county photo for a list of parcels. Reference only. |

## 17. How-to recipes

### Add a landmark replica
1. `python3 tools/pipeline/replica_add.py WORK KEY "Name" spec.json [az el]` registers it, exports the exact LiDAR massing, builds `assets/models/bld_KEY.glb` and renders `/tmp/prev_KEY.png`.
2. Edit `tools/blender/replicas/KEY/spec.json`, then rebuild with `bpyenv/bin/python tools/blender/replica.py tools/blender/replicas/KEY assets/models/bld_KEY.glb`.
3. Preview it: `bpyenv/bin/python tools/blender/preview_replica.py glb out.png AZ EL` (env `FOCUS="x,y,z,dist" RX= RY=`).

**Spec keys:**
- `materials` (body, trim, cornice, pier, frame, glass, shop_glass, roof, parapet, arch …);
- `bay`, `corner_pier`, `window{w,h,group,depth,mull,sill_frac}`;
- `parts[]`, each with:
  - `rect [cx,cy,w,d,ang]`, `rel`, or `poly`; `z0`/`z1`;
  - `floors[{n,h,kind:storefront|blank,arched,glass_h,wh}]`;
  - `cornice{h,out,profile}`, `parapet`, `merlons`, `roof{type:flat|gable|hip|pyramid|mansard}`;
  - `portal`, `chimneys`, `marquees[{edge,a0,a1,z0,z1,out,text,text_h,boards}]`, `mat_over`.
- top-level: `portico`, `dome`, `cupola`, `extras`, `tiers`, `drop_above`.

**Materials** are bound by name in `scripts/replicas.gd`; add new ones there and in `preview_replica.py` (COL).

### Take screenshots
Write a shotlist; get camera heights with `tz.py`; run the `--demo=shots` command (section 3). Look at the frames before sending them. **Screenshots only, no videos.**

### Rebuild part of the city fast
Run `build_city.py` with a small lat/lon bbox into `/tmp/x`, then copy just those `chunks/*.bin` into `data/chunks`. This works for chunks well inside the bbox.

### Make a character
1. `python3 tools/pipeline/face_landmarks.py photo.jpg photo.json dl/facefit/face_landmarker.task`.
2. Write a spec (section 7).
3. `bpyenv/bin/python tools/blender/charcreator/make_character.py spec.json out.glb preview.png` (`QUICK=1` renders the face only).

### Install MPFB2 on a new machine
1. Copy or link `mpfb2/src/mpfb` to `~/.config/blender/<ver>/extensions/user_default/mpfb`.
2. Link the MakeHuman asset folders (skins, hair, clothes, eyes, eyebrows, eyelashes, teeth, tongue, proxymeshes) into `~/.config/blender/<ver>/extensions/.user/user_default/mpfb/data/`.
3. In scripts: `addon_utils.enable("bl_ext.user_default.mpfb")`.


### Terrain grid vs. chunk ground (2026-11-21)
`Terrain.height()` (the coarse runtime height grid) can sit 0.5–3 m BELOW the chunk ground that `build_city.py` builds with `G()` (DEM plus raised road beds). Anything placed at runtime on a road or a lawn must raycast down onto the chunk collision (layer 1) and use `Terrain.height` only as the fallback. `parked_cars.gd _ground()` does this. Parked cars were sunk to their windows before it.

- **Don't wipe /tmp wholesale:** git commit signing runs through a helper in /tmp (`gpg.ssh.program`). Deleting it (2026-11-27, freeing disk for the city build) breaks `git commit`; commits since then use `git -c commit.gpgsign=false`.
- **Disk is tight (~5 GB free):** a full build needs ~1.6 GB in /tmp plus the data/ copy. Clear old renders and pip cache first, not /tmp helpers.
- **Repeating-pattern artifacts:** never bake low-frequency variation (stains, tone waves) into a tiling texture; it repeats every tile and reads as waves. Put it in world-space shader noise. To A/B lighting causes in screenshots, run with `GC_FX=nossil,nossao,hardsun,bias`.
